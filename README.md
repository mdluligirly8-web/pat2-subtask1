Morse Code

What is Morse Code?
Morse code is a way of sending messages using dots (.) and dashes (-). Each letter and number has its own pattern.

History
Morse code was created by Samuel Morse in the 1830s. It was used with the telegraph to send messages over long distances.

How it Works
A dot (.) is a short signal
A dash (-) is a long signal
Letters are made using dots and dashes

Examples
A = .-
B = -...
S = ...
O = ---

Words in Morse Code
HELLO = .... . .-.. .-.. ---
SOS = ... --- ...
Why it is Important

Morse code was one of the first ways to send messages electronically. It is still used in emergencies.
